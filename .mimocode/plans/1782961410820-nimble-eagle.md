## 技术分析

### DeepSeek-v4 的能力
1. **主要用途**：对话、代码生成、文本理解
2. **不支持**：文本向量化（embedding）功能
3. **API 端点**：只提供 chat completions 接口

### 为什么 DeepSeek-v4 不能直接用作 Embedding 模型

| 要求 | DeepSeek-v4 | Embedding 模型 |
|------|-------------|----------------|
| 输出类型 | 文本序列 | 固定维度向量 |
| API 端点 | `/v1/chat/completions` | `/v1/embeddings` |
| 模型架构 | Decoder-only | Encoder 或 专用架构 |
| 维度固定 | 否 | 是（如1536维） |

### 可行的替代方案

#### 方案1：使用 OpenAI Embedding API（推荐）
```python
# .env 配置
EMBEDDING_MODEL=text-embedding-3-small
EMBEDDING_BASE_URL=https://api.openai.com/v1
EMBEDDING_API_KEY=sk-xxx
```

需要修改 memory.py 以支持独立的 embedding API 配置。

#### 方案2：使用其他兼容的 Embedding 服务
- **智谱 (GLM)**：提供 embedding 接口
- **百川 (Baichuan)**：支持 embedding
- **本地模型**：如 sentence-transformers

#### 方案3：降级为关键词匹配（当前已实现）
- memory.py 已实现降级机制（第68-74行）
- 当 embedding API 不可用时，自动使用关键词匹配
- 效果较差，但无需额外 API

#### 方案4：模拟 Embedding（不推荐）
- 使用 DeepSeek-v4 生成伪向量
- 缺点：语义理解差、维度不固定、成本高

## 推荐方案

### 短期：保持现有降级机制
当前代码已实现自动降级，embedding 不可用时使用关键词匹配。

### 长期：配置独立的 Embedding 服务

修改 memory.py 以支持独立配置：

```python
# 需要添加的环境变量
EMBEDDING_BASE_URL=https://api.openai.com/v1
EMBEDDING_API_KEY=sk-xxx
EMBEDDING_MODEL=text-embedding-3-small
```

修改 `_get_embedding` 方法：
```python
def _get_embedding(self, text: str) -> list[float] | None:
    if not self._embedding_available:
        return None
    try:
        # 支持独立的 embedding API 配置
        embedding_base_url = os.getenv("EMBEDDING_BASE_URL")
        embedding_api_key = os.getenv("EMBEDDING_API_KEY")
        
        if embedding_base_url and embedding_api_key:
            # 使用独立的 embedding 客户端
            client = OpenAI(base_url=embedding_base_url, api_key=embedding_api_key)
        else:
            # 使用主 LLM 客户端
            client = self._llm.client
            
        resp = client.embeddings.create(
            model=os.getenv("EMBEDDING_MODEL", "text-embedding-3-small"),
            input=text,
        )
        return resp.data[0].embedding
    except Exception:
        self._embedding_available = False
        return None
```

## 结论

1. **DeepSeek-v4 不能直接用作 embedding 模型**
2. 当前项目的降级机制已经可以正常工作
3. 如需高质量语义搜索，建议配置独立的 embedding 服务（如 OpenAI text-embedding-3-small）
4. 无需修改代码即可使用关键词匹配作为备选方案
